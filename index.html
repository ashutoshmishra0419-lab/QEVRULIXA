Admin Corner

Instructions for adding PDF books to the site.

How to add a book

  1. Open your GitHub repository and choose Add file → Upload files.
  2. Upload your PDF, for example into a folder named books, and commit changes.
  3. Open index.html and click the pencil icon to edit.
  4. Find const BOOKS in the code and add your book's details and PDF path.
  5. Commit changes to publish the updated site.
Important: This is an instruction section, not a secure admin login. A real private login and direct PDF upload require a backend service.
